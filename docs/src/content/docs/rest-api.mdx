title: REST API reference
description: Every route in the v1 API, grouped by resource, with the method and path you'll actually call.
---

By the end of this page you will have the exact method and path for every route in Vessel's `/api/v1` surface, grouped the way the sidebar groups the product itself.

All routes are mounted under `<base-path>/api/v1` — `<base-path>` is `""` unless `--base-path` is set to something other than `/`. Every response is a view type defined in `internal/api` — no raw Docker Engine structs are ever returned to the client. Errors share one envelope; see [Troubleshooting](/vessel/troubleshooting/) for every `code` value.
